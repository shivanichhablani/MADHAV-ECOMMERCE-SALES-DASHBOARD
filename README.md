# MADHAV-ECOMMERCE-SALES-DASHBOARD

## Madhav E-commerce Sales Dashboard

An interactive **E-commerce Sales Dashboard** created using **Microsoft Power BI** to analyze sales performance and generate meaningful business insights.

### Key Features

* Analyzed **Sales, Profit, Quantity, and Orders**.
* Created interactive dashboards using **Power BI**.
* Used charts and visualizations to identify **sales trends and business performance**.
* Analyzed sales performance across different **categories, products, customers, and regions**.
* Added interactive filters and slicers for better data exploration.

### Tools & Technologies

* Microsoft Power BI
* Data Visualization
* Data Analysis
* DAX

### Objective

The main objective of this project is to transform e-commerce sales data into an **interactive and easy-to-understand dashboard** that can help businesses monitor performance and make **data-driven decisions**.
